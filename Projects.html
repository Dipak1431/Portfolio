COMPUTER NETWORK DESIGN AND IMPLEMENTATION

Jun 2020 To Nov 2020

Objective: To design network topologies for a small organisation in the first part of project, which has 240 work stations and perform OSPF routing protocols in different area networks, and in the second part of project, to apply routing with OSPF along with NAT-PT.

Key Tasks:

    ➜ Subnetting IP address for each device, and ports between Layer 3 switches and routers. ➜ Designing a topology for 5 departments by assigning layer 2 switch in each building department with VLANs to separate each department in different VLANs to reduce security risk by mitigating hosts receive copies frame. ➜ Implementing First Hop Redundancy Technology in Layer 3 switches in topologies to improve load balancing and fault-tolerance. ➜ Performing OSPF routing protocol in the second project based on a small-scale network, which can be supervised centrally. ➜ Applying NAT PT in router to allow IPv6 devices communicate IPv4 devices.

Outcome:

The topology was successfully designed with the implementation of VLANs, HRSP, and NAT in the first part of the project. In the second part of project, OSPF was applied in the given topology to allow the devices to communicate to others with the shortest path. NAT-PT was used to enable the communication between IPv6-only devices and IPv4-only devices and reduce the high cost of IPv6.
